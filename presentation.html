Project 01

VisionTrigger
— 是什麼？

  • 用手勢控制 macOS 的工具
  • 透過 MacBook 鏡頭即時辨識手勢
  • 觸發 Shortcuts、AppleScript 或 Shell 指令
  • 支援語音指令（Faster-Whisper）
  • 可自定義手勢與語音對應動作
Project 01 · AI 技術

VisionTrigger
— AI 技術核心

  • MediaPipe HandLandmarker：Google AI 手部骨架偵測模型
  • 21 個關節點即時追蹤，辨識手指伸展狀態
  • Faster-Whisper：高效語音轉文字（Whisper 模型優化版）
  • RMS 音量偵測語音活動，自動啟動辨識
  • 所有 AI 推論皆在本地端執行，無需網路
Project 01 · 開發歷程

VisionTrigger
— Claude Code 如何協助

  • 架構設計：單執行緒 OpenCV 主迴圈 + 兩條 Daemon 執行緒
  • 手勢狀態機：REG_IDLE → CAPTURE → NAME → ACTION → CONFIRM
  • 語音指令模板：{placeholder} 正則捕獲群組自動替換
  • 模組拆分重構：gestures / mac_trigger / voice / draw_utils
  • Claude Code 輔助撰寫、除錯與優化核心邏輯
Project 02

iTrace
— 是什麼？

  • Instagram 追蹤關係分析工具
  • 找出「你追蹤他，他不追蹤你」的帳號
  • 網址：itrace.stanleyowen.com
  • 兩種模式：離線（JSON 匯出）& 在線（DevTools 注入）
  • 所有資料在本地端處理，保護用戶隱私
Project 02 · 技術架構

iTrace
— 技術架構

  • 前端：JavaScript (79.7%) + CSS + HTML
  • 打包工具：Vite
  • 離線模式：匯入 Instagram 資料 JSON，本地比對分析
  • 在線模式：DevTools Console 腳本，疊加互動介面於 Instagram 頁面
  • 支援直接取消追蹤操作
Project 02 · 開發歷程

iTrace

  • 功能邏輯設計：following vs followers 差集演算法
  • UI 互動覆蓋層（Overlay）開發與樣式優化
  • ESLint 規範審查與程式碼品質提升
