VisionTrigger
— What is it?

  • Control macOS using hand gestures detected through your MacBook camera
  • Triggers Shortcuts, AppleScript, or any shell command
  • Also supports voice commands via Faster-Whisper (local, no internet)

④ 成果展示 · Project 01 · AI Technology

VisionTrigger
— AI at the Core

  • MediaPipe HandLandmarker — Google's AI model detects 21 hand joint points every frame
  • Finger state encoded as a (thumb, index, middle, ring, pinky) boolean tuple → gesture lookup
  • THUMBS_UP vs DOWN disambiguated by thumb-tip y-coordinate — subtle geometry trick
  • Faster-Whisper — optimized Whisper model for real-time speech-to-text transcription
  • RMS-based Voice Activity Detection → no constant mic streaming, only activates on sound
  • All AI inference runs 100% locally — no cloud, no latency, no privacy concern

④ 成果展示 · Project 02

iTrace
— What is it?

  • Instagram followback checker — find who you follow but who doesn't follow back
  • Live at itrace.stanleyowen.com
  • Online mode: script injected into Instagram DevTools console, fetches live data via Instagram's internal API and renders a floating overlay UI on top of instagram.com
  • Offline mode: upload Instagram data export JSON files, compare locally — no network calls
  • All data processed client-side — no backend, no accounts, full privacy
  • Supports bulk unfollow with rate-limit-safe throttling
④ 成果展示 · Project 02 · Architecture

iTrace
— Technical Architecture

  • Frontend: React + Vite (JavaScript 79.7%)
  • Offline mode: upload Instagram export JSON → local Set-difference algorithm
  • Online mode: injected vanilla JS overlay — no frameworks, runs anywhere
  • Pagination: walks all pages of /api/v1/friendships/ with throttle + retry
  • Rate limiting: configurable delay, jitter, and 5-cycle cooldown
  • Unfollow: POST to /web/friendships/{id}/unfollow/ with CSRF token

Core Algorithm

const followersSet = new Set(followers);
const notFollowBack =
  following.filter(u =>
    !followersSet.has(u));

Simple set difference — the hard part was getting the data, not computing the result.

⑤ 遭遇的困難 · The Hard Part

The Difficulty:
Instagram's Undocumented Private API

  • Instagram has no public API for reading your own followers/following list programmatically
  • The app calls an internal API not documented anywhere: /api/v1/friendships/followers/
  • Required identifying the right headers (e.g. x-ig-app-id: 936619743392459), auth cookies, and pagination parameters
  • The unfollow endpoint needed CSRF token extraction from cookies + correct POST format
  • AI alone could not figure this out — the API behavior had to be observed and verified manually

This is where human judgment became essential — not just writing code, but understanding a system that wasn't designed to be understood from the outside.

⑤ 遭遇的困難 · How I Solved It

How I Cracked It:
Postman + Manual Analysis

01
Capture traffic in DevTools Open Instagram in browser, inspect Network tab, filter by friendships to find the real API calls being made by the Instagram web app.
02
Replay in Postman Copy the request (headers, cookies, params) into Postman. Test each endpoint, observe the response structure, and confirm what fields are returned.
03
AI-assisted analysis Used AI to help parse the JSON schema, understand pagination (next_max_id), and design the retry + rate-limit logic around the discovered endpoints.

⑥ 感想 · Reflection

What I Learned

🤖

AI accelerates, not replaces  ·  AI 是加速器，不是替代品

VisionTrigger was fully vibe-coded — Claude Code + Copilot handled architecture, modules, and state machines. Complex software shipped in days, not weeks.

🧠

Some problems need human eyes  ·  有些問題只能靠人

iTrace required observing live network traffic, understanding undocumented API behavior, and manually validating every assumption — AI alone couldn't get there.

✅

Even “full AI” needs verification  ·  全 AI 也要驗證

This presentation was generated by AI in under 3 minutes — but a human still reviewed every slide, corrected details, and approved the final output.

🤝

Human judgment is the constant  ·  判斷力才是核心

Whether AI does 20% or 100% of the work, a human must verify the result is correct, honest, and actually says what you meant to say.
