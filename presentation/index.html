④ 成果展示 · Project 01 · AI & Development

VisionTrigger
— AI at the Core, Vibe-Coded End-to-End

AI MODELS · 核心模型

  • MediaPipe HandLandmarker — 21 joints per frame; finger state encoded as (thumb, index, middle, ring, pinky) bool tuple
  • Faster-Whisper — real-time speech-to-text, all local; no cloud or latency
  • RMS-based VAD: mic only activates on sound, not constant streaming
  • THUMBS_UP vs DOWN disambiguated by thumb-tip y-coordinate

VIBE-CODED · 用 AI 寫的

  • Single-threaded OpenCV loop + 2 daemon threads (action + voice)
  • Gesture state machine: IDLE → CAPTURE → NAME → ACTION → CONFIRM
  • Voice template matching: {placeholder} regex capture + substitution
  • Hot-patching: new gestures register without restart

Claude Code — handled full-stack: algorithms, UI drawing, config I/O, threading, refactoring.

GitHub Copilot — inline suggestions during active coding sessions.

Fruit Ninja
— Same Hand-Tracking, Now for Play

  • Reused VisionTrigger's hand-tracking pipeline — same MediaPipe model, same camera abstraction, different output
  • Built with Python + Pygame — 60 FPS game loop, sprite cache, persistent juice splat layer
  • 5 fruits (watermelon, orange, apple, lemon, kiwi) + bombs with animated fire
  • 3 solo difficulties — Easy/Medium/Hard tune lives, spawn rate, and required slice speed (700 → 1100 px/s)
  • Optional Kinect v2 via the same tracker abstraction

2v2 Multiplayer · 多人對戰

  • 4 players, one camera — MediaPipe tracks up to 4 hands at once
  • Hand IDs 0&1 → Team A (red), 2&3 → Team B (blue)
  • 90-second timed battle; higher score wins; bombs subtract 1 from your team

The motivation: VisionTrigger proved hands can replace the mouse. Fruit Ninja asked — can they also replace the controller, and bring friends into the same physical space instead of static, solo gameplay?

④ 成果展示 · Project 03

iTrace
— Instagram Followback Checker

  • Find who you follow but who doesn't follow back — live at itrace.stanleyowen.com
  • Online mode: script injected into Instagram DevTools, fetches data via Instagram's internal API, renders floating overlay
  • Offline mode: upload Instagram data export JSON — compared locally, zero network calls
  • All data client-side — no backend, no accounts, full privacy
  • Bulk unfollow with rate-limit-safe throttling + 5-cycle cooldown
  • Frontend: React + Vite; injected overlay: vanilla JS so it runs anywhere

Core Algorithm

const followersSet = new Set(followers);
const notFollowBack =
  following.filter(u =>
    !followersSet.has(u));

Simple set difference — the hard part was getting the data, not computing the result. That's the next slide.

⑤ 遭遇的困難 · The Hard Part

The Difficulty:
Instagram's Undocumented Private API

  • Instagram has no public API for reading your own followers/following list programmatically
  • The app calls an internal API not documented anywhere: /api/v1/friendships/followers/
  • Required identifying the right headers (e.g. x-ig-app-id: 936619743392459), auth cookies, and pagination parameters
  • The unfollow endpoint needed CSRF token extraction from cookies + correct POST format
  • AI alone could not figure this out — the API behavior had to be observed and verified manually

This is where human judgment became essential — not just writing code, but understanding a system that wasn't designed to be understood from the outside.

⑤ 遭遇的困難 · How I Solved It

How I Cracked It:
Postman + Manual Analysis

01
Capture traffic in DevTools Open Instagram in browser, inspect Network tab, filter by friendships to find the real API calls being made by the Instagram web app.
02
Replay in Postman Copy the request (headers, cookies, params) into Postman. Test each endpoint, observe the response structure, confirm what fields are returned.
03
AI-assisted analysis Used AI to parse the JSON schema, understand pagination (next_max_id), and design retry + rate-limit logic around the discovered endpoints.

⑥ 感想 · Reflection

What I Learned

🤖

AI accelerates, not replaces  ·  AI 是加速器

VisionTrigger + Fruit Ninja were both vibe-coded — and Fruit Ninja reused VisionTrigger's pipeline, so AI handled the “extend an existing system” loop too. Complex software shipped in days.

🧠

Some problems need human eyes  ·  有些問題只能靠人

iTrace required observing live network traffic and validating an undocumented API — AI alone couldn't get there. The line lives at “things AI has never seen.”

✅

Even “full AI” needs verification  ·  全 AI 也要驗證

This deck was AI-generated in < 3 minutes — but a human still reviewed every slide, corrected details, and approved the final output.

🤝

Human judgment is the constant  ·  判斷力才是核心

Whether AI does 20% or 100%, a human must verify the result is correct, honest, and actually says what you meant to say.
